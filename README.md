# AI-Powered Resume Parser & ATS Optimization System

An AI-powered ATS (Applicant Tracking System) Resume Screening web application developed using Flask, MySQL, NLP, and Machine Learning techniques.

This system analyzes resumes, calculates ATS scores, extracts skills, compares resumes with job descriptions, and automatically ranks candidates based on resume-job matching.

---

## Features

### User Module
- User Registration & Login
- Resume Upload
- ATS Score Calculation
- Skill Matching
- Missing Skill Detection

### Recruiter Module
- Multi Resume Upload
- Automatic Candidate Ranking
- Resume Comparison
- Top Candidate Shortlisting

### AI/NLP Features
- Resume Parsing
- Information Extraction
- Text Cleaning using NLP
- Cosine Similarity Matching

## Project Workflow

1. User uploads resume PDF
2. System extracts text from resume
3. Job description is analyzed
4. ATS score is calculated
5. Matching and missing skills are displayed
6. Recruiters can upload multiple resumes
7. System ranks candidates automatically
